# Hangman Game
## Description
This project is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Internship.
The player has to guess the hidden word one letter at a time. The player gets six incorrect attempts before the game ends.
## Features
- Randomly selects a word from a predefined list
- Allows the user to guess one letter at a time
- Displays the correctly guessed letters
- Gives a maximum of 6 incorrect attempts
- Displays win or lose messages
## Technologies Used
- Python
## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:
```bash
python main.py
```
